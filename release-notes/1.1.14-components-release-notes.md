# Release Notes - Version 1.1.14

## Overview
This release focuses on updating dependencies and excluding certain utility files from synchronization processes. There are no changes to the core components, but these updates ensure better package management and workflow efficiency.

## Component Changes

### General Updates
**Improved: Dependency Management**
- Updated dependencies in `package.json` and `package-lock.json`.
- This update ensures compatibility with the latest versions of external libraries and improves overall stability.

**Refactored: Workflow Configuration**
- Modified `.github/workflows/sync-to-public.yml` to exclude `sync_utils/` from synchronization.
- This change prevents unnecessary files from being included in public syncs, streamlining the workflow process.

## Technical Details
- No breaking changes introduced in this release.
- Compatibility remains unchanged as there are no modifications to the core components or their interfaces.

## Dependencies
- Updated dependencies in `package.json` and `package-lock.json` to their latest versions.
- Ensure your environment meets the updated requirements specified in these files for optimal performance.

This release does not include any changes to the components in the `src/Sys*Component/` folder, nor does it affect any gamified components.
