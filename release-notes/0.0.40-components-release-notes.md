# Release Notes - Version 0.0.40

## Overview
This release focuses on bug fixes and improvements across multiple components, addressing timezone handling, validation issues, browser compatibility, and user experience enhancements.

## Component Changes

### SysCalendarComponent
**Fixed: Date Display Timezone Issues**
- Fixed incorrect date display caused by timezone shifts
- Improved date formatting to handle UTC dates consistently
- Ensures dates appear correctly regardless of user's timezone

### SysPhoneInputComponent  
**Fixed: Validation for Non-Required Fields**
- Fixed validation errors appearing on empty non-required phone fields
- Validation now only triggers when user starts typing
- Improved async loading behavior and context handling

### SysDropdownInputComponent
**Fixed: Chromium Autofill Interference**
- Disabled unwanted autofill suggestions in Chrome/Chromium browsers
- Added `autocomplete="one-time-code"` workaround to prevent dropdown interference

### SysSliderComponent
**Fixed: Double Initialization on Shuffle**
- Fixed duplicate `WIDGET_INIT_SUCCESS` events when shuffling slides
- Replaced DOM manipulation with CSS-based reordering
- Maintains shuffle functionality without triggering component lifecycle

### SysNetPromoterScoreComponent
**Improved: Visual Spacing**
- Adjusted padding for score mark items
- Provides more consistent visual spacing between score selections

### Gamified Components (SysGiftBoxComponent, SysScratchCardComponent, SysWheelOfFortuneComponent)
**New: Prize Pool Persistence**
- Prize selections now persist in local storage after gameplay
- Users see their selected prize when revisiting the widget
- Applies to all gamified components:
  - Gift Box: Saves immediately after selection
  - Scratch Card: Saves after 1.5 seconds
  - Wheel of Fortune: Saves after 5 seconds

### SysColumnsComponent & SysContainerComponent
**Refactored: Configuration Structure**
- Moved layout select controls from component manifests to editor
- Cleaner separation of concerns between components and editor

## Technical Details
- No breaking changes
- All fixes maintain backward compatibility
- Improved overall stability and user experience

## Dependencies
- Updated to latest `@claspo/renderer` version
- Node.js >= 18.16.0 required
