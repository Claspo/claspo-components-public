# Release Notes - Version 1.1.13

## Overview
This release focuses on enhancing the functionality of the Claspo components with new features, improvements, and bug fixes. Key areas of focus include gamified components, improved input validation, and enhanced styling options for various components.

## Component Changes

### SysButtonComponent
**Improved: Button Styling**
- Added relative position and z-index 0 to the button for better layering and interaction.
- Removed unused loop animation parameters to streamline the component.

### SysPhoneInputComponent
**Fixed: Input Validation and Country Code Handling**
- Improved phone validation logic to handle country codes more accurately, including values pasted without a '+' sign.
- Addressed issues with flag icon visibility during initialization to prevent layout shifts.

### SysPromoCodeComponent
**Improved: Promo Code Display and Interaction**
- Enhanced promo code wrapping to ensure consistent display across editor and preview modes.
- Added target action tracking to better monitor user interactions with promo codes.

### SysImageComponent
**Improved: Floating Image Support**
- Implemented backward compatibility for floating flag located in the model root.
- Enhanced image positioning logic to support floating positions for custom components.

### SysSliderComponent
**Improved: Slider Functionality**
- Introduced swipe feature for sliders to improve user interaction on touch devices.
- Adjusted default settings for loop slides to enhance user experience.

### SysTextComponent
**Improved: Text Roller Animation**
- Customized text roller animation speed for better control over text display dynamics.
- Removed redundant code from font loading watch to fix early render issues with wrong positioning.

### SysColumnsComponent
**Improved: Column Management**
- Enabled column drag functionality to allow for more flexible layout adjustments.
- Updated background properties and sync modes for better styling consistency.

### Gamified Components (SysScratchCardComponent, SysGiftBoxComponent, SysWheelOfFortuneComponent)
**Added: Enhanced Gamification Features**
- Introduced new animations and improved prize pool management for gamified components.
- Enabled partial wheel visibility for the Wheel of Fortune component to enhance user engagement.

## Technical Details
- **Breaking Changes**: None reported.
- **Compatibility**: This version maintains backward compatibility with previous versions.
- **Other Technical Details**: Enhanced input validation and improved component styling options.

## Dependencies
- Updated various dependencies to ensure compatibility and improve performance.
- Environment requirements remain unchanged from the previous version.
